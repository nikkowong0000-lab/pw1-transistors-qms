# Time Management 怎麼改、怎麼交

## 你要交的檔（放進 QMS → Operations）

| 檔案 | 用途 |
|------|------|
| **`PW1_TM_SUBMIT.html`** | **主交件**：改黃色欄 → 列印 PDF／截圖 GANTT |
| `PW1_TM_Mahara_Paste.md` | 複製貼上 Mahara 的文字稿 |
| `PW1_GANTT_tasks.csv` | 用 Excel 改任務時間（進階） |
| `PW1_Time_Management.html` | 零基礎教學（不用交，給自己看） |

## 3 步搞定

1. 雙擊打開 **`PW1_TM_SUBMIT.html`**
2. 只改黃色「✏️ 改這裡」：組員名字、工時、風險短文
3. 按「列印 / 存 PDF」或截圖 **D. GANTT** → 上傳 Mahara；風險短文從同一頁或 `PW1_TM_Mahara_Paste.md` 貼上

可按「儲存我的修改」暫存在這個瀏覽器；交作業前仍建議另存 PDF。

## 改任務條（進階）

用記事本打開 `PW1_TM_SUBMIT.html`，搜尋 `const TASKS = [`，改 `name / day0 / s / day1 / e / type`。  
或改 `PW1_GANTT_tasks.csv` 後，手動同步 TASKS。
