# Open this Gantt in ProjectLibre

**File:** `PW1_TimeManagement_ProjectLibre.xml`  
(Microsoft Project XML / MSPDI — ProjectLibre can open it)

## If ProjectLibre is not installed

1. Download: https://www.projectlibre.com/ or SourceForge ProjectLibre
2. Install, then open ProjectLibre

## Open the file

1. ProjectLibre → **File → Open**
2. File type: **XML** / **MSProject XML** / All files
3. Select `PW1_TimeManagement_ProjectLibre.xml`
4. View → **Gantt Chart**
5. Turn on **Critical path** highlighting if available (Format / Gantt options)

## Edit before submitting

- Change assumed dates if your Week 6 is not **2–6 Nov 2026**
- Rename resources: Stream A/B/C → real teammate names
- Screenshot the Gantt (with critical path visible) for Mahara
